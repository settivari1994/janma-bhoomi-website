# Janma Bhoomi Developers — Modern Nature Luxury

Responsive, animated static React + Tailwind landing website built with Vite, Framer Motion and Lucide icons.

## Run locally

Requires Node.js 20.19+ or 22+.

```bash
npm install
npm run dev
```

Open the local address printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

Deploy the generated `dist/` directory to Vercel, Netlify or another static host. Vercel settings: framework Vite; build `npm run build`; output `dist`.

## Asset directory

`public/assets/` contains the original supplied Janma Bhoomi logo image, Oak Ocean logo image, Whispering Woods promotional artwork and two supplied MP4 clips. The videos are low-resolution promotional media and may contain embedded prices/ROI claims inconsistent with the poster. Replace with clean HD originals for best results. No stock images were introduced.

## Project data & publication checks

The 2/3/4 BHK configurations and indicative prices are copied from the supplied Whispering Woods artwork. The Oak Ocean logo refers to a distinct project identity and is displayed separately. **Do not assume these are the same project.** The poster indicates 42 villas on 12 acres, 6 km from Madikeri and 250 km from Bengaluru. Another supplied video includes differing villa counts and investment claims. Confirm with the developer before publication.

Claims such as guaranteed rental income, ROI and RERA compliance have intentionally **not** been repeated as verified promises. Obtain the RERA registration number and legally approved disclosures before publishing any such claims. Location links open Madikeri town rather than an unverified exact project pin.
